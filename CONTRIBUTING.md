# Contributing to NVL Support

Changes must keep the package tiny, transport-neutral, and free of dependencies on other NVL packages.

Test serialization safety, backed response-code enforcement, status boundaries, chaining, standalone installation, discovery, publication, and architecture constraints. Run Pest, Pint, PHPStan at maximum strictness, Composer validation, dependency analysis, and distribution validation.

DTOs, pagination, TypeScript, models, routes, migrations, and domain helpers belong elsewhere.
